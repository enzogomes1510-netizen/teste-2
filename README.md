# Desafio das Flores — interface ilustrada

- O menu principal agora usa a ilustração completa `menu-ilustrado.png` como a própria interface visual.
- Os botões desenhados na imagem são clicáveis por áreas transparentes sobrepostas: Jogar, Multiplayer, Configurações, Sobre, Sair e o controle de som.
- Cada partida individual seleciona 10 perguntas aleatórias sem repetição dentro da partida.
- A seção Sobre mostra “Feito por Gomes”.
- Os arquivos do projeto devem permanecer juntos ao publicar o site.
- O multiplayer depende da configuração do Firebase em `firebase-config.js`; a sincronização completa de uma partida entre computadores precisa ser configurada e testada antes de uso online.
